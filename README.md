autobuilds
==========
The latest builds can be found [here](https://github.com/DolceSDK2/autobuilds/releases/) for Windows (x64), Linux (x64), and OSX (Intel).

The scripts used for building can be found in [buildscripts](https://github.com/DolceSDK2/buildscripts) and the Vita specific sources can be found in the [DolceSDK](https://github.com/DolceSDK2) homepage.
